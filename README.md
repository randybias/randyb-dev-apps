# randyb-dev-apps

Small convenience applications for agentic software development. Each app
lives in its own top-level directory with its own README covering
requirements, install, and usage.

| App | Type | Use when | Docs |
|-----|------|----------|------|
| portwarden | MCP server | An agent session needs a local TCP port for a dev server, database, or mock API without colliding with other sessions. | [portwarden/README.md](portwarden/README.md) |
